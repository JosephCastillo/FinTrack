# Glosario - Glossary

| Término | Definición |
|---------|------------|
| **Documento de visión** | Documento que describe el problema, los objetivos y el alcance del producto antes de comenzar el desarrollo. |
| **Product Owner** | Persona responsable de definir qué valor debe entregar el producto y priorizar las necesidades del negocio. |
| **Sprint** | Periodo de trabajo con un objetivo y entregables definidos. |
| **Git** | Git es un Sitema de Control de Versiones Distribuido (Distributed Version Control System - DVCS). Permite registrar la evolución de un proyecto mediante instantáneas (commits), facilitando el seguimiento de cambios, la colaboración entre desarrolladores y la recuperación de versiones anteriores de forma segura.|
| **Snapshots** | Cada commit representa una fotografía del proyecto en un momento determinado.|
| **GitHub** | GitHub es una plataforma basada en Git que permite alojar repositorios remotos, colaborar con otros desarrolladores, gestionar cambios mediante **Pull Request**, registrar incidente (Issues) y aoutomatizar procesos de desarrollo medinate herramienta como GitHub Actions.|
| **Repositorio** | Es la carpeta raíz de nuestro proyecto (por ejemplo, FinTrack/). Contiene todo nuestro árbol de archivos de trabajo: código fuente, imágenes, documentación y configuraciones. Es la carpeta con la que interactuamos día a día.|
| **.gitignore** | Es un archivo de configuración que le inidica a Git qué archivos o carpetas no deben formar parte del repositorio porque son generados automáticamente, específicos del entorno local o contienen información que no debe compartise. |
| **LICENSE** | Especifica los términos legales bajo los cuales el software es distribuido. Define qué permisos tienen otras personas para usar, modifica, copiar y redistribuir el proyecto, así como las obligaciones que deben cumplir.|
| **README** | Es el documento principal de un proyecto. Su objetivo es explicar qué hace el software, por qué existe, cómo está organizado, cómo ejecutarlo, qué tecnologías utiliza y cómo contribuir a su desarrollo.|
| **gitadd** | Selecciona qué cambios pasarán al próximo commit.
